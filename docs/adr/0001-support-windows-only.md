# Support 64-bit Windows only

Dictum supports 64-bit Windows on Intel/AMD (`x86_64-pc-windows-msvc`) and ARM (`aarch64-pc-windows-msvc`). It does not support 32-bit Windows. macOS, Linux, Android, and iOS code may remain when inherited from Handy, but the project will not spend effort rebranding, maintaining, testing, or extending those platforms. This keeps the work focused on the two Windows builds that matter to Dictum while avoiding an unrelated platform-removal project.
